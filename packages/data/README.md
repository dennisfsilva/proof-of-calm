# @proofofcalm/data

The "Proof of Calm reference close" daily price history derived from exchange public data (Kraken,
Bitstamp, Coinbase) with ECB reference rates for currency conversion, plus `DATA-LICENSE.md` naming
the sources and dates. Never raw exchange files. Refreshed by the scheduled job. Decisions: ADR-0006,
ADR-0036, ADR-0037. Created in milestone M2.
