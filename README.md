# proof-of-calm

Proof of Calm is a calm, noise-free crypto DCA planner and educator. Set up a plan once, log each monthly purchase in
under a minute, see where you are in the plan and what the holding rules of your country mean for each
purchase. Custody-free, minimal account, usable without one. No news, no sentiment, no alerts.
